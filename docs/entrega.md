# Entrega e apresentação

Envie ao professor o endereço https://github.com/trvalle/mba-ia-desafio-harness-legado e indique a branch **main**. A entrega acadêmica é o fork público com código, scripts, gates, hook, AGENTS.md, CLAUDE.md, README e registro de incidentes. Nenhum envio ao professor foi feito automaticamente.

O material complementar principal é **docs/relatorio-final.html**. Abra o arquivo local no navegador com duplo clique; não exige servidor, instalação ou conexão. Ele contém explicação do desafio, arquitetura, requisitos e evidências filtráveis, screenshots reais, resultados, limitações, glossário, perguntas do professor e roteiros de30 segundos,1 minuto e5 minutos. Pode ser entregue junto, sem substituir o fork.

Resultados técnicos comprovados:33/33 unitários;51/51 da suíte oficial em cada cópia;19/19 violações do kit;2/2 próprias;17/17 adversariais. Login/triagem/upload/download/isolamento/reinício e bloqueios do hook foram exercitados. Código avaliado e1d5c9f; a resposta final informa o commit publicado que inclui os materiais.

O relatório diferencia os39 requisitos acadêmicos dos17 complementares. Status e números vêm de requisitos.json e resultados.json, não de estimativa. A aprovação declarada representa os critérios disponíveis, nunca uma nota oficial garantida.

Para demonstrar, no WSL ou Linux/macOS, abra a raiz e execute npm run up. Use os endereços informados e as contas de demonstração no README. Rode npm run gates. Crie uma segunda worktree pelo comando documentado e repita up; demonstre que um chamado/anexo de A não aparece em B. Encerre cada cópia com npm run down.

Os alertas de dependências e a particularidade do relógio WSL estão documentados. Testes de integração herdados e macOS não foram executados; cobertura de linhas não foi coletada. Preserve a transparência sobre o trabalho dos agentes ao apresentar o projeto.
